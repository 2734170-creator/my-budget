✅ Результаты:
- ✅ Таблица `profiles` создана:
  - id (UUID, FK → auth.users)
  - full_name (TEXT)
  - avatar_url (TEXT)
  - created_at (TIMESTAMPTZ)
- ✅ Таблица `households` создана:
  - id (UUID, PRIMARY KEY)
  - name (TEXT, NOT NULL)
  - currency (TEXT, DEFAULT 'RUB', CHECK RUB/USD/EUR)
  - created_by (UUID, FK → profiles)
  - created_at (TIMESTAMPTZ)
- ✅ Таблица `household_members` создана:
  - id (UUID, PRIMARY KEY)
  - household_id (UUID, FK → households)
  - user_id (UUID, FK → profiles)
  - role (TEXT, DEFAULT 'member', CHECK owner/member)
  - joined_at (TIMESTAMPTZ)
  - UNIQUE(household_id, user_id)
- ✅ RLS включён для всех трёх таблиц
- ✅ Политики безопасности настроены (6 политик):
  - profiles: SELECT, UPDATE (только свой профиль)
  - household_members: SELECT, INSERT (только своё членство)
  - households: SELECT, INSERT (только свои домохозяйства)
- ✅ Функция триггера `handle_new_user()` создана
- ✅ Триггер `on_auth_user_created` привязан к `auth.users`
- ✅ Тестовая регистрация через админ-панель прошла успешно
- ✅ Файл миграции сохранён: supabase/migrations/20260213000000_init_schema.sql
- ✅ Файл .gitignore создан для защиты секретов
